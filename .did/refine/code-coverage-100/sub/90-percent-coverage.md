# Sub-Task: Reach 90% Line Code Coverage (Prerequisite for 100% Coverage)

## Overview
Achieves 90% line code coverage across `src/commands.rs`, `src/main.rs`, and `src/repo.rs` as a prerequisite step toward 100% code coverage.

## Requirements
1. Add targeted unit/integration tests to reach 90% line coverage.
2. Update CI workflow gate to `--fail-under-lines 90` in `.github/workflows/test.yml`.
