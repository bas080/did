# Feature Specification: Fuzzy Search & Typo Tolerance for `did query`

## Overview
Enhances `did query` (and alias `did search`) with zero-dependency fuzzy subsequence matching and relevance ranking so typos do not produce zero matches.

## Decision
Implement a lightweight, zero-dependency custom subsequence matching algorithm directly in `src/commands.rs`.

## Approach
- Matching algorithm checks if all characters in the search query appear sequentially in the target string (case-insensitive).
- Assigns relevance scores giving bonus points for consecutive character matches, word boundaries (after `/`, `-`, `_`, `.`, space), and exact substring matches.
- Ranks results by highest score so direct matches appear first, followed by typo-tolerant fuzzy matches.
