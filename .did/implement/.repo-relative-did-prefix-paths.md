# Repository-Relative `.did/` Path Output for AI Agents and Shell Tools

Format all CLI output paths relative to the repository root (prefixed with `.did/`), allowing AI agents and shell scripts to directly pass output paths into file tools without path ambiguity.

## Before & After CLI Output Examples

### `did add "My Note"`
```
# Before
My-Note.md

# After
.did/My-Note.md
```

### `did status`
```
# Before
refine/auth.md
implement/ui.md

# After
.did/refine/auth.md
.did/implement/ui.md
```

## Requirements
- Update `relative_display_path` in `src/repo.rs` to format paths relative to the repository root (including `.did/`).
- Ensure all subcommands (`add`, `status`, `query`, `show`, `log`, `fzf`) print valid `.did/` paths.
- Ensure all tests pass.
