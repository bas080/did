# Non-Interactive CLI Improvements for AI Agents and Scripts

Enhance `did` CLI for non-interactive execution (CI/CD, scripts, and AI agents):
1. Print created file relative path on `stdout` when running `did add`.
2. Include actionable `did init` hint when `.did` state directory is missing.
3. Suggest `did help <cmd>` on usage/argument errors.

## Before & After Output Examples

### `did add "My Note"`
```
# Before
(silent exit code 0)

# After
My-Note.md
```

### Missing `.did` State Directory
```
# Before
error: no .did state directory found.

# After
error: no .did state directory found. Run 'did init' to initialize a repository.
```

## Requirements
- Output created relative path on stdout in `did add`.
- Include `did init` hint when repo is missing.
- Ensure all tests pass.
