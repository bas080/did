# Sub-Issue: `did tree [PATH]` & `did status --tree`

## Overview
Subcommand and status flag for rendering a visual directory tree showing task hierarchies, sub-items, completion statuses, and dependency links.

---

## Detailed Requirements

1. **Tree Hierarchy Output**:
   - Renders task directories, files, and symlink dependencies in an ASCII tree format (`did tree [PATH]` or `did status --tree`).
   - Displays parent-child relationships, completion statuses (active vs. dot-prefixed resolved items), and blocking dependencies.
2. **Depth Limiting (`-L <DEPTH>`)**:
   - Accepts `-L` / `--level` to limit tree rendering depth.
3. **Task Status Color-Coding**:
   - Color-codes actionable leaf tasks, blocked nodes, and resolved (dot-prefixed) tasks.
