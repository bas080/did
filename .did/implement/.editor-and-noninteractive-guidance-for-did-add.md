# Interactive $EDITOR and Non-Interactive Guidance for `did add`

Enhance `did add` so that:
- In interactive terminal (TTY) mode: if no title or stdin is provided, open `$EDITOR` (falling back to `$VISUAL`, `nano`, or `vim`) with a temporary template file to let the user write the note interactively.
- In non-interactive terminal (non-TTY) mode: print friendly instructions showing how AI agents and scripts can create notes non-interactively via title arguments or piped stdin.

## Before & After CLI Examples

### Non-Interactive Mode (e.g. scripts/agents)
```
# Before

# After
error: note title or piped stdin required for 'did add'

To create a note non-interactively (for scripts and AI agents), use one of the following methods:

1. Pass a title argument:
   did add "Title of the note"

2. Pipe body content with a title:
   echo "Note body content" | did add "Title of the note"

3. Pipe markdown directly into did:
   echo -e "# Note Title\n\nDetailed body description..." | did
```

## Requirements
- Support interactive `$EDITOR` launch in TTY mode when no arguments/stdin are supplied.
- Provide clear non-interactive instructions in non-TTY mode.
- Ensure all tests pass.
