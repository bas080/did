# Rejected Proposal: `did clean-log` Subcommand

## Overview
Proposes a `did clean-log` subcommand to clear or truncate telemetry log files generated via `DID_LOG_PATH`.

---

## Decision: WON'T IMPLEMENT (`.did/wont/`)

### Rationale
- **Uncommitted Local Artifacts**: Telemetry logs generated by `DID_LOG_PATH` are local development artifacts (e.g. `target/did.log`) that should be added to `.gitignore` and never committed into Git state or tracked inside `.did/`.
- **Standard Shell Tools**: Clearing or rotating log files is naturally handled by standard shell utilities (e.g. `> target/did.log` or `rm target/did.log`).
